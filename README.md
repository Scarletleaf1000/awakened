# Awakening
### A mod inspired by Brandon Sanderson's _Warbreaker_
Awakening is a mod designed to recreate the Cosmere's breath system from nalthis. This mod contains minor spoilers for _Warbreaker_.

Breaths can be gained by killing high breath individuels or by trading with villagers. Breaths grant passive bonuses and allow you to awaken (or animate) inanimate objects with commands.
